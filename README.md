# 🛒 E-Commerce Customer Churn Analysis

## 📌 Project Overview
Analyzed 5,630 customer records to identify churn patterns 
and provide business recommendations using Python, SQL and Power BI.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQL (CTEs, Window Functions, Joins)
- Power BI (Interactive Dashboard)

## 📊 Key Findings
- 16.84% customer churn rate
- Churned customers average only 3.9 months tenure
- Tier 1 cities have highest churn
- Debit card users churn most
- Complainers churn at 50% rate

## 💡 Business Recommendations
- Target customers inactive for 60+ days
- Offer loyalty rewards after 6 months
- Improve complaint resolution process
- Focus retention in Tier 1 cities
